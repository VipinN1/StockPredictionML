# LSTM Stock Predictor

This part of the project predicts stock prices using historical data with an LSTM model.

## Project Structure

- `data/`: Contains stock and ETF historical data and metadata.
- `utils.py`: Helper functions for loading and preprocessing data.
- `lstm_model.py`: Main training and evaluation script.
